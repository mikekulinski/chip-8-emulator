A basic implementation of the CHIP-8 emulator written in Rust. 

I used the following as guides: 
- https://tobiasvl.github.io/blog/write-a-chip-8-emulator/#logical-and-arithmetic-instructions
- http://devernay.free.fr/hacks/chip8/C8TECH10.HTM#8xy1

And reused the amazing test suites provided by:
- https://github.com/Timendus/chip8-test-suite
